# Hipertúnel

Runner de túnel en primera persona inspirado en Boost 3D. Demo interna.

## Jugar ya
- Abre `index.html` en el navegador del ordenador (necesita conexión), o `hipertunel-movil.html` (funciona sin conexión).
- Para el **giroscopio en el móvil** hay que abrirlo desde una web https. Lo más rápido: arrastra la carpeta a app.netlify.com/drop, o pídele a Claude Code que lo publique en GitHub Pages.

## Seguir desarrollándolo con Claude Code
1. Descomprime esta carpeta donde quieras y ábrela en una terminal.
2. Ejecuta `claude` y dile, por ejemplo:
   > Lee CLAUDE.md y sigue desarrollando el juego desde aquí. Primero instala, pasa las pruebas y haz capturas para ver cómo está. Luego publícalo en GitHub Pages para que funcione el giroscopio.
3. Todo el contexto (reglas de diseño aprendidas, estructura del código, pruebas y siguientes pasos) está en `CLAUDE.md`.

## Carpetas
- `index.html`: el juego (versión 0.31).
- `hipertunel-movil.html`: el mismo juego con las librerías incluidas.
- `tests/`: simulación con bot, comprobaciones de calidad y capturas automáticas.
- `referencias/`: el vídeo del original y sus fotogramas, las imágenes de estilo y capturas de tu móvil.
